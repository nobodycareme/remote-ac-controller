# 首次配置指南

本指南覆盖 **三种**最常见的首次配置场景：普通家庭/实验室 WPA/WPA2 WiFi、西电 Srun 校园网、以及**完全不配置任何凭据**的离线构建。**所有真实凭据**（WiFi 密码、校园账号密码）**只存放在本地 untracked 文件中，仓库内只提交 `.example.h` 模板**。请勿把任何凭据写入 `platformio.ini`、build_flags、串口日志、终端历史或 CI 日志。

固件的功能开关统一由 [`firmware/shared/RemoteACCore/src/config/feature_gates.h`](../../firmware/shared/RemoteACCore/src/config/feature_gates.h) 控制，每一组合法组合与非法组合均在该头文件中以编译期 `#error` 形式强制约束。

---

## A. 普通家庭/实验室 WPA 或 WPA2 WiFi

> 适用场景：你家或办公室的 WiFi 是 WPA/WPA2 加密（密码至少 8 位），不需要 Portal 认证。
> 本场景编译宏：`ENABLE_WIFI=1 ENABLE_WIFI_CREDENTIALS=1 ENABLE_AUTO_WIFI_CONNECT=1 ENABLE_CLOUD=0`。

### A.1 准备本地凭据

真实凭据放在 `wifi_secrets.h`，**该文件被 git-ignore，仓库内绝不提交**。

```powershell
cd firmware/shared/RemoteACCore/src/config
cp wifi_secrets.example.h wifi_secrets.h
```

编辑 `wifi_secrets.h`：

```cpp
#define LOCAL_WIFI_SSID     "你的WiFi名称"
#define LOCAL_WIFI_PASSWORD "你的WiFi密码"
```

### A.2 选择 PlatformIO 编译 Profile

`dev.ps1` 提供两个本地 WiFi Profile：

| Profile | 含义 | ENABLE_CLOUD |
|---|---|---|
| `local-wifi` | 家庭/实验室 WiFi，无云连接 | 0 |
| `local-wifi-cloud` | 家庭/实验室 WiFi + 云端（MQTT/HTTPS） | 1 |

**先编译并烧录**（platformio-cli 自带上传；不需要手动选择串口——`dev.ps1` 会自动检测 CH9102 等设备）：

```powershell
cd firmware/agent-platformio
./tools/dev.ps1 build -Profile local-wifi
./tools/dev.ps1 build -Profile local-wifi-cloud
```

### A.3 Arduino IDE 模式

在 Arduino IDE 中打开 `firmware/arduino-ide/Remote_AC_Controller/Remote_AC_Controller.ino` 后，在 `globals.h`（或 sketch 顶部的 `secrets` 区域）按以下顺序配置：

```cpp
#define ENABLE_WIFI              1
#define ENABLE_WIFI_CREDENTIALS  1   // 启用本地 WPA 凭据
#define ENABLE_AUTO_WIFI_CONNECT 1   // 上电自动连接

// 普通 WiFi 凭据（与 PlatformIO 路径相同）
#include "config/wifi_secrets.h"
```

> 通用 Arduino IDE 操作见 [Arduino IDE 使用指南](Arduino-IDE使用指南.md)。

### A.4 运行时串口命令

固件上电后会自动用编译进二进制的本地凭据连接家庭 WiFi（`WIFI_AUTOCONNECT_ON_BOOT`）。如需手动连接或切换到开放 SSID，可在串口 monitor 中执行：

| 命令 | 行为 |
|---|---|
| `wifi connect` | 重新连接 `wifi_secrets.h` 中的家庭 WiFi（WPA 路径，密码不入串口） |
| `wifi connect stu-xdwlan` | 显式连接西电开放 SSID（`wifi_secrets.h` 不被读取） |
| `wifi status` | 打印当前 NET_STATE / NET_SSID / LOCAL_IP / MAC（MAC 已脱敏） |
| `wifi scan` | 列出附近 AP（只读） |
| `wifi disconnect` | 断开当前关联 |

**串口日志中绝不出现** 密码内容、密码长度、密码前缀片段或任何可恢复信息，只输出：

```
WIFI_CONNECT ssid=<ssid> security=WPA_OR_WPA2
WIFI_CONNECT ssid=<ssid> security=OPEN
```

### A.5 安全约束（feature_gates.h 编译期强制）

- `ENABLE_WIFI_CREDENTIALS=1` 必须有 `ENABLE_WIFI=1`，否则 `#error`。
- `ENABLE_AUTO_WIFI_CONNECT=1` 必须有 `ENABLE_WIFI=1`，否则 `#error`。
- 校园网（`ENABLE_CAMPUS_AUTH=1`）与本地 WiFi 凭据是**互不依赖**的两条路径。
- 公开构建不包含 `wifi_secrets.h`；`wifi_secrets.h` 已加入 `.gitignore`。
- 不得将 WiFi 密码写入：
  - `platformio.ini`；
  - `build_flags`；
  - 命令行历史；
  - 串口日志（已通过 WiFiManager 强制实现）；
  - CI 环境日志；
  - README 示例的真实值（请用 `your_wifi_name` / `your_wifi_password` 占位符）。

## B. 西电 Srun 校园网

> 适用场景：西电校园 WiFi `stu-xdwlan`（开放 SSID，无 WPA 密码），需要 Portal 认证。
> 本场景编译宏：`ENABLE_WIFI=1 ENABLE_CAMPUS_AUTH=1 ENABLE_AUTO_CAMPUS_AUTH=1 ENABLE_CONTROLLED_LIVE_AUTH=1 ENABLE_AUTO_WIFI_CONNECT=1 ENABLE_CLOUD=0`。
> **注意**：西电 Srun 仅作为公开示例 Profile（`profiles/xidian.example.h`）。其他 Srun 部署可参考 [Srun 校园网移植指南](Srun校园网移植指南.md)。

### B.1 准备 Profile 与校园凭据

```powershell
cd firmware/shared/RemoteACCore/src/config
# 1. 复制公开示例 Profile（可继续使用 STU-XDWLAN 默认值；如要自定义可改 xidian.h）
cp profiles/xidian.example.h profiles/xidian.h
# 2. 准备校园 Portal 凭据
cp campus_secrets.example.h campus_secrets.h
```

编辑 `campus_secrets.h`：

```cpp
#define CAMPUS_USERNAME "你的学号"
#define CAMPUS_PASSWORD "你的校园网密码"
```

> **不要**在 `campus_secrets.h` 之外的任何文件中保存这些值，**不要**在 `platformio.ini` 或 `globals.h` 中写明文密码。

### B.2 选择 PlatformIO 编译 Profile

```powershell
cd firmware/agent-platformio
./tools/dev.ps1 build -Profile local-campus-example
```

`local-campus-example` 启用了校园自动认证（`ENABLE_AUTO_CAMPUS_AUTH=1`）但未启用 `ENABLE_CONTROLLED_LIVE_AUTH=1`——**该 Profile 编译时若 `campus_secrets.h` 仍是 example 占位符会无法通过编译期校验**。请先按 B.1 配置真实凭据。

### B.3 Arduino IDE 模式

```cpp
#define ENABLE_WIFI                 1
#define ENABLE_CAMPUS_AUTH          1
#define ENABLE_AUTO_WIFI_CONNECT    1
#define ENABLE_AUTO_CAMPUS_AUTH     1
#define ENABLE_CONTROLLED_LIVE_AUTH 1
#define CAMPUS_PROFILE_HEADER       "profiles/xidian.h"
#include "config/campus_secrets.h"
```

### B.4 安全警告（feature_gates.h 编译期强制）

- 不得提交 `campus_secrets.h`（已 `.gitignore`）。
- 不得把密码写入 `platformio.ini` 或 `globals.h`。
- 不得使用 `setInsecure()` / 关闭 TLS 校验。
- 公共 Profile 不得编译真实学号/密码（`ENABLE_CONTROLLED_LIVE_AUTH=0` + `ENABLE_AUTO_CAMPUS_AUTH=1` 在公共构建中是编译期禁止的）。
- TLS 指纹不匹配时必须立即停止认证：`BAD_CREDENTIALS` / `WRONG_DOMAIN` / `TLS_PIN_MISMATCH` 三种结果会直接进入 `BLOCKED` 状态，不自动高频重试。
- 每小时配额（`CampusAuthPolicy` 的 `quota_hourly_limit`）、最小间隔、失败退避、硬阻断闩锁均由 `campus_auth_policy.h` 统一控管，**不得在 WifiManager 中重复实现**。

完整细节见 [西电校园网自动认证](西电校园网自动认证.md) 与 `firmware/shared/RemoteACCore/src/network/campus_auth_policy.h`。

## C. 离线构建（不配置任何真实凭据）

> 适用场景：仅需使用 DHT11 温湿度、串口 CLI、安全只读功能。无需任何凭据。

```powershell
cd firmware/agent-platformio
./tools/dev.ps1 build -Profile public
```

`public` Profile 默认：
- `ENABLE_WIFI=1`
- `ENABLE_CLOUD=1`（云连接开启，但**不编译云端凭据**——`cloud_secrets.h` 仍为 example 占位符）
- `ENABLE_CAMPUS_AUTH=0`
- `ENABLE_WIFI_CREDENTIALS=0`
- `ENABLE_AUTO_WIFI_CONNECT=0`（默认行为：固件上电**不**自动连接任何 WiFi，等 `wifi connect` 命令）

如果你的应用需要 `ENABLE_CAMPUS_AUTH=0` 且 `ENABLE_AUTO_WIFI_CONNECT=0`，固件会保持 offline-first 行为：上电时 WiFi 灯不会亮、不会有任何自动连接、串口只读模式（`session.role !== 'owner'`）下可以查看状态但不能发送红外指令。

## 常见问题

**Q：编译报 `ENABLE_WIFI_CREDENTIALS=1 requires ENABLE_WIFI=1`？**
A：忘了 `-DENABLE_WIFI=1`。`platformio.ini` 默认就开启了，但 Arduino IDE 模式需在 `globals.h` 显式 `#define ENABLE_WIFI 1`。

**Q：`dev.ps1 build -Profile local-wifi` 报 `WIFI_SECRETS_MISSING`？**
A：还没在 `firmware/shared/RemoteACCore/src/config/wifi_secrets.h` 填 SSID/密码。脚本已指引复制 `.example.h`。

**Q：烧录后上电 30 秒仍在 `WIFI_DISCONNECTED`？**
A：用 `wifi status` 查看当前状态、`wifi scan` 确认 SSID 可见、确认 WPA 密码大小写正确（普通家庭路由器对大小写敏感）。`WIFI_CONNECT ssid=...` 日志会告诉你走的是 WPA 还是 OPEN 路径。

**Q：能否把 `wifi_secrets.h` 提交到 Git？**
A：**不能**。`wifi_secrets.h` 已被仓库的 `.gitignore` 忽略。**只**提交 `wifi_secrets.example.h` 占位符。

**Q：如何更新 WiFi 密码？**
A：编辑本地 `wifi_secrets.h`，**重新编译并烧录**。本项目没有「运行时修改 WiFi 凭据」的接口（避免凭据外泄）。
