# 版本管理

## 版本号体系

- **软件版本**：`vX.Y.Z`（语义化版本，Semantic Versioning），由根 `VERSION`
  文件统一决定，适用于固件、后端、前端与文档。
- **PCB 修订**：`Rev x.y.z`，独立于软件版本，记录在
  `hardware/pcb/REVISION`。

两者相互独立：PCB 修订变化不需要软件版本变化，反之亦然。

## 软件版本变更

- 修改根 `VERSION` 后，同步更新：
  - `cloud/VERSION`、`firmware/agent-platformio/VERSION`
  - `cloud/backend/package.json` 与 `package-lock.json`
  - `cloud/frontend/package.json` 与 `package-lock.json`
  - `firmware/shared/RemoteACCore/src/app_config.h` 的 `FIRMWARE_VERSION`
  - `docs/doc-map.json` 的 `version` 字段
- `tools/check-version.py` 动态读取根 `VERSION` 并校验以上全部文件，
  同时校验启动横幅不产生双 `v`。

## 启动横幅约定

- 固件常量：`#define FIRMWARE_VERSION "vX.Y.Z"`（含 `v` 前缀）。
- 启动横幅前缀不含 `v`：`Remote AC Controller  firmware `，与常量拼接后
  显示 `firmware vX.Y.Z`。
- `version` 命令与遥测字段直接输出 `vX.Y.Z`（单 `v`）。

## 标签与不可变性

- 发布用 **annotated tag**（`vX.Y.Z`），只推送该 tag。
- 标签不可移动、不可重写、不可删除后重建。
- 发布后发现问题 → 发布补丁版本，不修改已发布标签。

## PCB 修订变更

- PCB 修订流程见 [PCB 发布流程](./PCB发布流程.md)；修订号记录在
  `hardware/pcb/REVISION` 与 `hardware/pcb/CHANGELOG.md`。
