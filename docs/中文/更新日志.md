# 更新日志

## [1.2.6] - 2026-08-03

### 修复

- 使用已验证并固定摘要的 Mosquitto 2.1.2 Alpine 镜像，恢复全新克隆的 Compose 可复现性。
- Broker 健康检查改用后端 MQTT 账号认证，ACL 仅新增 `$SYS/broker/version` 读取权限。
- Docker 前后端构建均改为复制锁文件并执行 `npm ci`。
- 安全命令闭环合同修正为 `blocked_by_ir_policy` / `real_ir_control_disabled`。
- Owner 登录统一使用 `WEB_USER` 与 `WEB_PASSWORD`，旧 `IR_OWNER_*` 变量不再影响授权。
- 新增跨平台 scrypt Owner 密码哈希生成工具及自检模式。

### 说明

- Cloud API、数据库结构、MQTT 主题、PCB 数据和真实 IR 数据均未改变；PCB 仍为 Rev 1.0.1。
- 真实 IR 默认关闭，仍需 Owner、Origin、CSRF、服务端策略、状态白名单和设备侧策略全部通过。

## [1.2.5] - 2026-08-02

### 修复

- **MQTT TLS 指纹真正应用到运行时**：`MqttClientWrapper::begin()` 通过统一的 TLS 身份策略与可注入适配器把 CA 或 SHA-1 指纹应用到 BearSSL 客户端；仅配置有效指纹时实际调用 `setFingerprint()`。
- **CA 优先、指纹回退**：同时配置有效 CA 与有效指纹时只使用 CA；没有有效 CA 时才使用指纹；两者都缺失时 `begin()` 返回 false，输出 `TLS_MATERIAL_MISSING` / `TLS_FINGERPRINT_INVALID`。
- **修复含空格 SSID 被错误拒绝**：`Home WiFi`、`Lab Network 2` 等含普通空格的 SSID 现在合法。
- **统一 32 字节 SSID 上限**：新增单一 C++ 规则（1-32 UTF-8 字节、拒控制字符、拒全空格、拒模板值），Python 构建期校验与 `wifi connect <ssid>` 运行时使用同一规则。
- **Python 与 C++ SSID 规则一致性测试**：共享测试向量，二者返回相同的 valid/errorCode。

### 说明

- Cloud API、数据库、MQTT 消息格式和 PCB 无破坏性变化；PCB 保持 Rev 1.0.1。
- 推荐长期部署优先使用 CA 证书；指纹在证书更新后失效，需要同步更新。

## [1.2.4] - 2026-08-02

### 修复

- **本地 WPA 开机后的 SSID 状态**：连接来源明确化（本地 WPA / 校园开放 SSID / 运行时开放 SSID / 无），开机后 `wifi status` 与日志显示的实际 SSID 与真实连接一致。
- **`wifi connect <ssid>` 被本地 WPA 配置覆盖**：显式开放 SSID 不再被编译期本地凭据覆盖；`wifi connect`（无参数）恢复本地 WPA 配置。
- **真实连接路径的 Host 集成测试**：通过可注入的关联接口直接测试生产连接函数。
- **拒绝未修改的 Cloud 秘密模板**：构建前与运行时的内容校验会拒绝模板主机、无效端口、模板设备 ID、模板账号密码与缺失 TLS 材料。
- **强化 TLS 配置验证**：本地 Cloud 配置至少需要一个有效 CA 证书或 TLS 指纹。

### 说明

- 固件、云端 API 与数据库格式无破坏性变化；PCB 保持 Rev 1.0.1。

## [1.2.3] - 2026-08-02

### 修复

- **无凭据 public 构建的自动联网策略**：`WIFI_AUTOCONNECT_ON_BOOT` 不再由 `ENABLE_CLOUD` 单独触发。编译 Cloud 模块并不提供 SSID 与连接身份，`public` 与 `public-cloud-example` 现在不会在开机时自动关联网络。
- **空 SSID 硬保护**：SSID 为空时打印 `WIFI_CONNECT_SKIPPED reason=SSID_NOT_CONFIGURED`，不调用任何 `WiFi.begin()` 重载，状态保持断开；本地 WPA 密码为空时同样跳过。
- **local-wifi-cloud 语义修正**：该 Profile 现在启用 `ENABLE_CLOUD_CREDENTIALS=1` 并要求本地 `cloud_secrets.h`；缺少 `wifi_secrets.h` 或 `cloud_secrets.h` 时构建直接停止。
- **文档事实错误修正**：README 删除"只部署固件即可手机控制""模拟设备""组件随意替换""任意 ESP8266 板可直接运行"等无代码依据的表述；首次配置指南改用真实的 `Remote_AC_Controller.ino.globals.h` 文件名；西电校园网指南修正 `local-campus-example` 的真实能力（`ENABLE_AUTO_CAMPUS_AUTH=0`、不读取真实凭据、不自动登录）。

### 说明

- 固件、云端 API 与数据库格式无破坏性变化；PCB 保持 Rev 1.0.1。

## [1.2.2] - 2026-08-02

### 新增

- **普通家庭/实验室 WPA/WPA2 WiFi 配置**：新增 `firmware/shared/RemoteACCore/src/config/wifi_secrets.example.h` 占位符模板与 `ENABLE_WIFI_CREDENTIALS` / `ENABLE_AUTO_WIFI_CONNECT` 编译开关；`wifi connect` 无参数命令使用编译进固件的本地凭据；`local-wifi` / `local-wifi-cloud` PlatformIO Profile 已加入 `dev.ps1` 并实际编译验证。密码从不出现在串口日志、build_flags、CI 环境或 README 示例。
- **首次配置指南（成对中英文）**：`docs/中文/首次配置.md` / `docs/English/first-time-setup.md`，覆盖普通 WiFi、西电校园网与离线三种模式。
- **Windows CI IR 学习工具门禁**：新增 `ir-simple-learner-windows` Job（`windows-latest` + Python 3.12），执行锁定依赖安装、两份 IR 单元测试、20 轮稳定性测试、正式 `build.ps1 -Clean`、EXE `--self-test`、SHA-256 计算、凭据/真实 IR 扫描并上传 EXE 为 CI Artifact。
- **正式 build.ps1（Python 3.12 + PyInstaller 6.21.0）**：原生命令执行辅助函数（System.Diagnostics.Process）修复 PowerShell 5.1 stderr 误判；`requirements-lock.txt` 精确锁定并校验哈希；`--self-test` / `--version` 写报告文件供无控制台 EXE 使用。
- **中英文 README 界面预览**：新增桌面端（1440×900）与移动端（390×844）控制界面演示截图，全部来自本地前端与合成演示数据。

### 修复

- 修复 IR 学习工具状态机：`ir.learn.cancelled` 事件与 `State.EXITING` 分支的互斥 if/elif 结构导致退出完成状态永远不可达，状态卡在 EXITING；重构后 12 项单元测试全通过并连续 20 轮稳定。
- 修复 IR 学习工具预设数量断言：正式合同为 10 组预设，测试改为单一权威断言并新增 codeId 唯一性检查；两份工具副本保持一致（`tools/check-ir-tool-parity.py` 强制校验）。
- 修复 v1.2.1 正式构建链问题：requirements-lock.txt 锁定 PyInstaller 6.21.0（与正式构建一致），build.ps1 从干净环境经锁定依赖可完整重建 EXE。
- 修复中英文 README 顶部导航链接（中文使用中文标题定位点）与可见 `.md` 后缀链接显示名。
- 清理固件文档漂移：移除 `v0.4.0-cloud-foundation` 过时版本号、`campus_credentials.h` 过时路径表述，版本统一为 v1.2.2。

### 安全

- WiFi 凭据与校园网凭据严格分离（`wifi_secrets.h` / `campus_secrets.h` 均 git-ignored），任何模式下密码都不写入日志。
- 新增编译期非法组合 `#error`：`ENABLE_WIFI_CREDENTIALS` / `ENABLE_AUTO_WIFI_CONNECT` 依赖 `ENABLE_WIFI`，普通 WiFi 凭据与校园认证互斥。

### 已知问题

- 实际空调红外帧不在公开仓库中，需使用红外学习工具自行采集。
