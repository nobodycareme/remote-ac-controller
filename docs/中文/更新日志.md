# 更新日志

本项目所有重要变更均记录于此。本仓库采用 Monorepo 布局，将 ESP8266 固件与云端后端/前端合并到同一段发布历史中。

## [1.0.0] - 2026-07-31

首个正式公开发布版本。

### Added
- Remote AC Controller 系统的首次公开开源发布。
- **完整 Monorepo**：固件、云端、前端、文档合并为单仓库。
- **固件双模式**：PlatformIO Agent 自动化模式与 Arduino IDE 手动编译模式，共用同一套核心业务源码。
- **ESP8266 固件**：DHT11 温湿度采集、MQTT/TLS 安全通信、11 状态红外空调控制。
- **Cloud 后端**：Fastify + MQTT 桥接、定时调度引擎、双阈值温控自动化、天气数据获取与缓存、Owner/Guest 权限模型、受信任设备、遥测记录。
- **Vue 3 前端**：响应式跨设备界面、11 状态控制面板、定时管理、温控规则编辑。
- **PCB 设计文件**：EasyEDA Pro 源文件、Gerber 制造文件、钻孔文件、BOM、嘉立创下单资料。
- **红外学习工具**：源码 + Windows x64 EXE（CH9102 串口采集）。
- **中英文完整文档**：21 篇中文 + 20 篇英文。
- **GitHub Actions CI**：PlatformIO、Arduino CLI、Cloud、Repo Hygiene 四路并行。
- 采用 Apache License 2.0 授权。

### Security
- 不包含任何生产凭据、私钥、真实红外数据、数据库或生产环境文件。
- 公开的固件与云端默认值均为非生产安全值。
