# 西电校园网自动认证

> **ESP8266 上电自动认证西安电子科技大学校园网** — 连接校园开放 SSID 后，自动完成 Wi-Fi 关联、DHCP 地址获取、Captive Portal 探测、Srun 认证和互联网连通性确认。

---

## 概述

本功能允许 ESP8266 NodeMCU 在上电后自动连接到西电校园网（基于 Srun 4000 认证系统），无需手动打开浏览器进行 Portal 认证。设备连接校园开放 SSID 后，自动完成完整的认证流程，随后可继续连接 MQTT 云服务。

**功能默认关闭**，需用户显式配置启用。

## 工作原理

```
ESP8266 上电
  → 初始化 DHT11、红外模块、串口 CLI
  → 如果 ENABLE_WIFI=1：启动 Wi-Fi，连接校园 SSID
  → 获取 DHCP 地址
  → 如果 ENABLE_AUTO_CAMPUS_AUTH=1：执行 Captive Portal 检测
  → 如检测到 Portal：执行 Srun 认证
  → 验证互联网连通性
  → 如果 ENABLE_CLOUD=1：启动 MQTT 和遥测
  → 持续监控 Wi-Fi、互联网和 MQTT 状态
```

## 支持的宏定义

| 宏 | 默认值 | 说明 |
|----|--------|------|
| `ENABLE_WIFI` | 1 | 控制 Wi-Fi 硬件和连接 |
| `ENABLE_CAMPUS_AUTH` | 0 | 控制 Captive Portal 探测和 Srun 认证 |
| `ENABLE_AUTO_CAMPUS_AUTH` | 0 | 控制上电是否自动执行 Portal 检测与认证 |
| `ENABLE_CLOUD` | 0 | 控制 MQTT 和云连接 |

## 配置步骤

### 1. 启用校园网认证

在 `config.h`（Arduino IDE）或 `campus_credentials.h`（PlatformIO）中设置：

```cpp
#define ENABLE_WIFI 1
#define ENABLE_CAMPUS_AUTH 1
#define ENABLE_AUTO_CAMPUS_AUTH 1
```

### 2. 配置校园网参数

西电校园网 Profile 参数：

| 参数 | 说明 | 西电值 |
|------|------|--------|
| Wi-Fi SSID | 校园开放 SSID | `XDU` 或 `STU-XDU`（视校区而定） |
| Portal Host | Portal 服务器地址 | 需根据实际网络环境确定 |
| ac_id | 认证接入 ID | 根据校区和网络类型确定 |
| 账号格式 | 学号/工号 + 运营商后缀 | 学号 + `@运营商`（如 `@cmcc`） |
| 认证算法 | Srun 挑战-响应 | Srun 4000 标准 MD5 算法 |

### 3. 配置校园网凭据

凭据必须保存在 **git-ignored** 的文件中，不得提交到仓库：

```cpp
// 在 campus_credentials.h 中（已 git-ignored）
#define CAMPUS_USERNAME "your_student_id"
#define CAMPUS_PASSWORD "your_password"
```

复制模板文件并填写：

```bash
cp campus_credentials.example.h campus_credentials.h
# 编辑 campus_credentials.h 填入你的学号和密码
```

## 串口输出状态

认证过程中，串口（115200 波特率）会输出关键状态信息：

```
WIFI_CONNECTING ssid=XDU
WIFI_CONNECTED ip=10.x.x.x
PORTAL_DETECTING host=portal.xidian.edu.cn
PORTAL_DETECTED=YES
CAMPUS_AUTH_STARTING
CAMPUS_AUTH_OK internet=REACHABLE
CLOUD_MQTT_INIT_OK
```

认证失败时：

```
CAMPUS_AUTH_FAILED reason=PORTAL_UNREACHABLE
CAMPUS_AUTH_BACKOFF next_attempt=30s
```

## 安全说明

- **凭据仅存在于本地忽略文件**，不进入 Git 仓库
- 支持 TLS 证书验证，**不得关闭 TLS 验证**
- 具备认证频率限制和失败退避机制
- 日志中不输出完整账号密码
- Portal 响应不完整打印，避免泄露敏感信息

## 限制

- 本配置**仅针对西电校园网（Srun 4000）**适配
- 其他学校的 Srun 系统可能需要调整 Profile 参数
- 默认不启用自动认证，需用户显式配置
- 用户必须使用自己有权使用的校园网账号
- 请遵守学校网络使用规定
