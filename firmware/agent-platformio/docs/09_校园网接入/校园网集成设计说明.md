# 校园网接入 设计说明（Phase 5 / 7 / 9 实现）

- **固件版本**：`1.1.2-campus-wifi-integration`
- **文档时间**：2026-07-17
- **身份约束**：仅“校园网”身份，禁止电信/联通/移动，用户名不带任何运营商后缀（`@lt`/`@yd`/`@dx` 均不允许）。
- **凭据约束**：真实账号/密码来自 `secrets.h`（git-ignored，绝不入源码/日志/文档/ZIP）。未提供凭据时所有“真实登录/联网验证”一律标记为 `AUTH_BLOCKED_NEEDS_LOCAL_CREDENTIALS`，不伪造成功。

## 2. Wi-Fi 状态机（`WifiManager`）

- **非阻塞**：`update()` 每 `loop()` 调用一次；在 `wifi connect` 之前为 `NET_IDLE` 空转，不干扰既有 DHT/IR 行为。
- **关联**：`begin(ssid)` 配置 STA（持久化关闭、不自动重连，由本模块显式管理），`connect()` 发 `WiFi.begin`；30s 超时、最多 3 次重试。
- **关联后判定**：成功关联后做门户检测；若命中门户→`NET_PORTAL_DETECTED`，否则做 HTTPS 联网探测；443 可达→`NET_ONLINE`。
- **链路看守**：`ASSOCIATED/PORTAL_DETECTED/ONLINE` 态下若 `WiFi.status()!=WL_CONNECTED` → 5s 后自动重连（`NET_RECONNECTING`）。
- **门户检测**：接受两种特征之一即判 `PORTAL_DETECTED`：
  1. 明文 HTTP 探测返回 **3xx** 且 `Location` 含 `campus.example.edu`；或
  2. 返回 **200** 且响应体含 `portal.campus.example.edu` 拦截表单（校园透明 HTTP 拦截，详见 `08_校园网接入/校园网门户取证.md`）。
- **联网探测**：对知名主机做 **HTTPS GET**；校园门户在认证前会拦截/重置 443，故 200 即代表真实互联网可达。

## 3. srun 认证客户端（`CampusAuth`）

- **端点**（Phase 4 实证）：`challenge = GET /cgi-bin/get_challenge`；`login = POST /cgi-bin/srun_portal`；`logout = POST /cgi-bin/srun_portal`（action=logout）；主机 `portal.campus.example.edu`；`ac_id=8`。
- **密码编码**：`hmd5 = md5( md5(password) + token )`（srun type=2）。
- **info 字段**：用户 JSON（`username/password(明文)/ip/ac_id/enc_ver=srun_bx1`）经 token 逐字节 XOR 再 base64。
- **chksum**：`sha1(ac_id + username + hmd5 + token + ip)`（**变体需真实凭据验证**，见第 5 节）。
- **安全**：模块本身永不打印 token/密码；调用方在记录服务器响应前必须剥离敏感字段。

## 4. CLI 命令（受 `ENABLE_WIFI` 保护）

```
wifi connect [ssid]   # 关联 OPEN 校园 SSID（默认 stu-xdwlan），不自动连
wifi disconnect       # 断开关联
wifi scan             # 只读扫描附近 AP
wifi status           # NET_STATE / LOCAL_IP / MAC / SSID
net check             # 门户检测 + 联网探测，输出 CAPTIVE_PORTAL / INTERNET
campus status         # 认证状态；无凭据 → AUTH_BLOCKED_NEEDS_LOCAL_CREDENTIALS
campus login          # 尝试 srun 登录（需 secrets.h 真实凭据）
campus logout         # 尽力 srun 登出
```

开机**不**自动联网；保持既有“本地 IR 控制、无自动 IR 流量”的设计哲学，Wi-Fi 完全由用户显式触发。

## 5. 待真实凭据验证的事项（诚实标注）

以下项**代码已实现并编译**，但其**具体编码变体必须由真实校园网凭据在设备上验证**；现阶段无凭据，故一律 `AUTH_BLOCKED_NEEDS_LOCAL_CREDENTIALS`，不宣称可用：

1. `chksum` 字段拼接顺序（各校区定制，存在多套变体）。
2. `info` 的 xor/base64 细节与 `enc_ver` 取值。
3. `ac_id=8` 是否就是“校园网”身份对应的控制器（实证指向是，但仍建议首次登录后复核）。
4. 登录成功后返回的“online”判定字段（已兼容 `suc_true`/`error:"ok"`/`res:"ok"` 多种）。

> 说明：ESP8266 上无成熟维护的 srun Arduino 库，故按 Phase 4 实证提取的 `Portal.js` 算法直接实现；实现集中、单点可调，便于首次真实凭据接入时按返回微调。
