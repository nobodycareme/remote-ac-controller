# 硬件接线与引脚分配（权威版）

> 所有信号均为 3.3 V 逻辑。引脚定义的唯一真实来源为
> `include/config/hardware_config.h`；本文件与其保持一致。
> 历史接线（DHT11 @ D2/GPIO4）已废弃，归档于 `WIRING_legacy_GPIO4.md`，
> 废弃原因见 `../05_故障排查/历史问题与结论修正.md`。

## 1. 引脚总表
| 功能 | 模块脚 | NodeMCU 丝印 | ESP8266 GPIO | 方向 / 说明 |
|------|--------|--------------|--------------|-------------|
| 温湿度供电 | DHT11 VCC (+) | 3V3 | — | 3.3 V |
| 温湿度数据 | DHT11 DATA (S) | **D1** | **GPIO5** | 单总线；已验证良好（30/30 + 133/133） |
| 温湿度地 | DHT11 GND (-) | GND | — | 共地 |
| 红外供电 | ZJ-IR-V2 VCC | 3V3 | — | 3.3 V（首测；勿接 5 V） |
| 红外地 | ZJ-IR-V2 GND | GND | — | 共地 |
| 红外→MCU | ZJ-IR-V2 TXD | **D5** | **GPIO14** | 模块 TX → MCU RX |
| MCU→红外 | ZJ-IR-V2 RXD | **D6** | **GPIO12** | MCU TX → 模块 RX |

代码引用（集中定义）：
```cpp
constexpr uint8_t DHT11_DATA_PIN = D1;   // GPIO5
constexpr uint8_t IR_UART_RX_PIN = D5;   // GPIO14 (module TXD -> MCU RX)
constexpr uint8_t IR_UART_TX_PIN = D6;   // GPIO12 (MCU TX -> module RXD)
// SoftwareSerial 构造顺序为 (RX, TX)
```
向后兼容别名见 `include/board_pins.h`（`DHT_PIN` / `IR_RX_PIN` / `IR_TX_PIN`）。

## 2. 共地（强制）
```
NodeMCU GND
├── DHT11 GND
└── ZJ-IR-V2 GND
```
两模块必须与 NodeMCU 共地。NodeMCU 接 PC 时，勿再把 USB-TTL 接到红外模块。

## 3. ZJ-IR-V2 方向识别
- **黑色元件** = 红外接收（学习）：遥控器对准它。
- **透明元件** = 红外发射（发码）：对准空调接收窗。

## 4. 禁用 / 规避引脚
- **GPIO6–GPIO11**：接板载 Flash，禁止使用。
- 规避启动脚：**D3/GPIO0、D4/GPIO2、D8/GPIO15**。
- 本项目 D1/GPIO5、D5/GPIO14、D6/GPIO12 均在安全集合内。

## 5. 上电前检查
- [ ] NodeMCU 经 Micro-USB 数据线接 PC。
- [ ] DHT11：VCC→3V3，DATA→**D1**，GND→GND。
- [ ] ZJ-IR-V2：VCC→3V3，GND→GND，TXD→D5，RXD→D6。
- [ ] 共地已确认。
- [ ] 红外模块未额外接 USB-TTL；未施加 5 V（首测仅 3V3）。
- [ ] 串口号运行时自动检测，未硬编码 COM。
