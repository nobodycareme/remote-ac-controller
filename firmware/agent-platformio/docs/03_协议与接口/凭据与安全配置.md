# 凭据与安全配置

> 本文件说明校园网账号密码如何安全加载、为何绝不误提交真实凭据，以及启动期
> 最小可见性原则。

## 1. 凭据来源（单一事实来源）

- 真实凭据**仅**可来自 `include/secrets.h`（不入库、不提交）。
- 加载头：`include/config/campus_credentials.h`，使用
  `#if __has_include("secrets.h")` 检测，命中则 `#include "secrets.h"` 并
  标记 `HAVE_SECRETS_H`；否则 `CAMPUS_USERNAME` / `CAMPUS_PASSWORD` 定义为空串。
- 所有编译单元统一通过 `CampusCredentials::username()` / `password()` / `ready()`
  读取，避免多份定义不一致。

## 2. 模板与占位

- `include/secrets.example.h` 提供模板：
  ```cpp
  #define CAMPUS_USERNAME "YOUR_CAMPUS_ACCOUNT"
  #define CAMPUS_PASSWORD "YOUR_CAMPUS_PASSWORD"
  ```
- 占位值**不等于**真实凭据；当 `secrets.h` 缺失时，`CampusCredentials::ready()` 为
  `false`，设备进入 `AUTH_BLOCKED_NEEDS_LOCAL_CREDENTIALS`，不发起任何登录。

## 3. 启动期最小可见性

启动仅打印：
- `CAMPUS_CREDS_READY=YES` 或 `CAMPUS_CREDS_READY=NO`
- `TLS_PIN_CONFIGURED=YES` 或 `TLS_PIN_CONFIGURED=NO`

**绝不**打印：用户名、密码、token、info 字段、chksum、拼接后的完整登录 URL、
`ac_id`/domain 等可拼接出凭据的细节（常量配置可在非凭据上下文中记录，但不得与
实际账号值同屏出现）。

## 4. 三重门禁（未全过不得提交真实登录）

| 门禁 | 检查 | 失败结果 |
| --- | --- | --- |
| 凭据 | `CampusCredentials::ready()` | `AUTH_BLOCKED_NEEDS_LOCAL_CREDENTIALS` |
| TLS | `tlsPinValid()`（指纹固定可建立） | `TLS_PIN_REQUIRED` / `TLS_PIN_MISMATCH` |
| 算法 | `SRUN_ALGORITHM_VECTOR_PASS` | `SRUN_IMPLEMENTATION_FAIL` |

顺序：`nodemcuv2_campus_auth` 启动 → 凭据 → TLS → 算法 → 参数（SSID/ac_id/domain/后缀）
→ 全部通过才 `campusLogin()`。

## 5. 安全红线

- 真实 `secrets.h` 必须加入 `.gitignore`（本项目已排除）。
- 即使凭据就绪，也**只在**指纹固定 HTTPS 下发送；`setInsecure()` 仅限
  `INSECURE_PROBE_ONLY` 门户探测，且不含任何凭据。
- 登录失败分类（`BAD_CREDENTIALS` / `WRONG_DOMAIN` / `TLS_PIN_MISMATCH`）触发
  状态机 `BLOCKED`，**不自动重试、不踢其他终端、不自动注销**。
- 本仓库不持有任何私钥、token、服务端账户；审查包敏感扫描覆盖这些模式。
