# 项目总览 — 手机远程控制空调（NodeMCU ESP8266）

## 1. 目标
用 **NodeMCU ESP8266 (ESP-12E)** 采集环境温湿度（DHT11 / XHT11）并通过红外
（ZJ-IR-V2 学习 / 发码模块）控制空调，最终经 Wi-Fi + 云 + 手机网页实现远程控制。
当前阶段聚焦**本地固件与传感/红外链路的可靠性验证**，尚未接入 Wi-Fi / 云。

## 4. 硬件与关键参数
- 主板：NodeMCU ESP8266 (ESP-12E)，PlatformIO board `nodemcuv2`，Arduino 框架。
- USB-UART：CH9102（VID:PID `1A86:55D4`），串口 115200 8N1，端口运行时动态检测。
- DHT11 数据脚：**D1 / GPIO5**（当前正式方案；旧的 D2/GPIO4 方案是否与自定义驱动缺陷相互独立、并未用 Adafruit 做单变量验证，详见历史问题）。
- 红外：TXD→D5/GPIO14、RXD→D6/GPIO12，SoftwareSerial 惰性开启。
- 依赖：`adafruit/DHT sensor library@1.4.7` + `adafruit/Adafruit Unified Sensor@1.1.15`。

## 5. 构建环境（PlatformIO）
- 生产环境：`[env:nodemcuv2]`（DHT11 + IR CLI）。
- 只读探测：`[env:nodemcuv2_probe]`（`-DDISABLE_DHT`，仅红外只读探测）。
- 构建须走 NO_PROXY 直连绕过本地 MITM 代理，禁用 `PLATFORMIO_OFFLINE`。
