# 软件架构与模块说明

固件版本：`1.1.0-dht11-adafruit-integration`　·　框架：Arduino / ESP8266

## 1. 分层结构
```
main.cpp                  启动与主循环（无 Wi-Fi / 无自动红外流量）
├── config/hardware_config.h   引脚唯一真实来源（DHT11=D1, IR=D5/D6）
├── board_pins.h               向后兼容 shim（旧别名 → hardware_config）
├── app_config.h               固件常量（版本 / 波特率 / 采样间隔 / IR 帧常量）
├── sensors/dht11_sensor.*     正式 DHT11 传感器模块（封装 Adafruit DHT 库）
├── ir_module.*                ZJ-IR-V2 红外模块（SoftwareSerial 惰性开启）
└── serial_cli.*               串口命令行（所有红外操作均需显式命令触发）
```

## 2. 引脚集中管理（三层）
1. `hardware_config.h`：所有物理引脚的唯一定义（`DHT11_DATA_PIN`、`IR_UART_RX_PIN`、
   `IR_UART_TX_PIN`）。
2. `board_pins.h`：薄兼容层，把旧名字（`DHT_PIN` / `IR_RX_PIN` / `IR_TX_PIN`）
   映射到集中定义，供 `ir_module.*`、`serial_cli.cpp` 等旧代码继续编译。
3. 各模块：优先直接包含 `hardware_config.h`；新代码不应再硬编码 GPIO。

## 3. DHT11 传感器模块（`Dht11Sensor`）
封装广泛验证的 **Adafruit DHT 库 1.4.7**（Phase 1 在 D1/GPIO5 上 30/30 通过），
取代旧自定义驱动 `dht_service.*`（其 `rawTrace()` 在 `noInterrupts()` 临界区内调用
`Serial.print`，破坏单总线时序；旧测试还绑定了 GPIO4 通道，但 D2/GPIO4 是否有独立异常
未用 Adafruit 做单变量验证）。

公开 API：
| 方法 | 说明 |
|------|------|
| `begin()` | setup 中调用一次，初始化底层驱动 |
| `read()` | 立即强制读取一次，成功（温湿度均非 NaN）返回 true |
| `update(intervalMs)` | 距上次读取达到间隔才读，本次读取并成功返回 true |
| `hasValidReading()` | 最近一次读取是否有效 |
| `temperatureC()` / `humidityPercent()` | 最近有效温度 / 相对湿度 |
| `lastReadTimestamp()` | 最近读取的 `millis()` |
| `failureCount()` / `successCount()` | 累计失败 / 成功次数 |

采样间隔 `DHT_READ_INTERVAL_MS = 2500`（Adafruit 库强制 ≥2s，取 2.5s 留余量）。

## 4. 红外模块（`IrModule`）
- 基于 SoftwareSerial（RX=D5/GPIO14，TX=D6/GPIO12），**惰性开启**：不主动收发。
- 默认探测波特率 `IR_DEFAULT_BAUD = 115200`（8N1）。
- 帧常量：帧头 `0x68`、帧尾 `0x16`；模块地址 `0xFF`；回复超时 3000 ms。
- learn / emit 均需经 CLI 显式命令，且当前需用户授权后才执行。

## 5. 串口 CLI（`Cli`）
- 启动打印 banner + 版本；`status` 输出含 `dht_valid / dht_temp_c / dht_hum_pct /
  dht_ok / dht_fail` 与 `free_heap`。
- `dht read` / `dht test`：Adafruit 库读取（D1/GPIO5，@2.5s）。
- `ir ...`：红外只读探测 / 学习 / 发码（受权限门控）。
- 主循环仅 `gCli.handle()` + `yield()`，周期性温湿度读取由 CLI 内部按间隔驱动。

## 6. 构建环境
| 环境 | 用途 | 关键差异 |
|------|------|----------|
| `nodemcuv2` | 生产（DHT11 + IR CLI） | `build_src_filter = +<*>`；lib_deps Adafruit DHT + Unified Sensor |
| `nodemcuv2_probe` | 只读 IR 探测 | `-DDISABLE_DHT`；排除 `sensors/dht11_sensor.cpp`，DHT 引脚置高阻 |

## 7. 明确排除项（本期）
无 Wi-Fi、无 MQTT / 云、无自动红外发码、无手机端页面。这些属后续阶段。
