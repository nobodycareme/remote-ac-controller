# 环境与构建说明

## 1. 目录布局（纯英文路径）
| 路径 | 用途 |
|------|------|
| `F:\PIO\Core` | PlatformIO Core（`PLATFORMIO_CORE_DIR` 指向） |
| `F:\PIO\Projects\Remote_AC_Controller` | 本固件工程 |
| `F:\PIO\Downloads` | 依赖归档暂存 |
| `F:\PIO\Archives` | 工程外备份（清理安全网） |
| `F:\PIO\红外资料` | 厂家红外资料 |

> 统一使用 `PLATFORMIO_CORE_DIR`，弃用非官方 `PLATFORMIO_HOME_DIR`。

## 2. 关键环境变量
```bash
export PLATFORMIO_CORE_DIR="F:\PIO\Core"
export PATH="<PIO_ROOT>/Core/penv/Scripts:$PATH"
export NO_PROXY=".platformio.org,platformio.org,.espressif.com,espressif.com,127.0.0.1,localhost"
export PYTHONUTF8=1
# 注意：不要设置 PLATFORMIO_OFFLINE（6.1.19 会挂死）
```
pio 启动器：`F:\PIO\Core\penv\Scripts\pio.exe`。

## 3. 平台 / 工具链锁定版本
- 平台：`espressif8266 4.2.1`
- 工具：`toolchain-xtensa 2.100300.220621`、`framework-arduinoespressif8266 3.30102.0`、
  `tool-esptoolpy 1.30000.201119`、`tool-esptool 1.413.0`、`tool-mklittlefs 1.203.210628`、
  `tool-mkspiffs 1.200.0`、`tool-scons ~4.40801.0`（首次 `pio run` 解析缓存）。
- 库依赖：`adafruit/DHT sensor library@1.4.7` + `adafruit/Adafruit Unified Sensor@1.1.15`。

## 4. 构建命令
```bash
# 生产环境
pio run -e nodemcuv2 > build.log 2>&1

# 只读 IR 探测环境
pio run -e nodemcuv2_probe > probe.log 2>&1
```
后台构建建议：`( pio run -e nodemcuv2 > log 2>&1; echo "BUILD_DONE_EXIT=$?" >> log ) &`，
轮询日志中的 `BUILD_DONE_EXIT` 判完成（勿用 `| tee`）。

## 5. 烧录与串口
- 端口运行时动态检测（CH9102，VID:PID `1A86:55D4` → 通常 COM6），不硬编码。
- PowerShell 自动化脚本：`tools/detect_port.ps1` / `build.ps1` / `upload.ps1` /
  `monitor.ps1` / `smoke_test.ps1`；采集用 `tools/serial_collect.py`。
- `.ps1` 必须用 PowerShell 执行（Bash 会误解释 `$env:`）。
